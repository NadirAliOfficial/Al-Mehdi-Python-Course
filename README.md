# Al Mehdi Foundation Python Course

Daily Python class material for Al Mehdi Foundation — notebooks, exercises, and reference code.

## Description
This repository contains example Python scripts used in the Al Mehdi Foundation Python course. The scripts demonstrate basic data handling with **pandas** and **numpy**, as well as simple data visualisation using **matplotlib**. They serve as reference implementations for classroom exercises.

## Features
- Create and display a pandas DataFrame with sample tasks (w7d3.py).
- Demonstrate reading, modifying, and saving CSV data (read_write.py – commented examples).
- Plot task completion data with matplotlib (test.py).

## Contents
- Daily class notebooks
- Practice exercises
- Project assignments

## Requirements
```
pip install jupyter
jupyter notebook
```

## Installation
Install the required Python packages:
```
pip install pandas numpy matplotlib
```

## Configuration
No environment variables are required for the current scripts.

## Usage
Run the example scripts directly:
```
python w7d3.py      # Displays a sample task DataFrame
python read_write.py # Contains example code for CSV read/write (currently commented out)
python test.py       # Generates a task completion plot
```
